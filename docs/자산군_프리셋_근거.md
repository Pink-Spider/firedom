## 3. 공통 유의사항 (앱 "가정 보기"·면책에 반영)

1. **원화 환산 미반영**: 해외자산 수치는 전부 USD 기준. 환노출(언헤지) 보유 시 USD/KRW 변동이 추가되며, 분산은 상관을 반영해 결합되므로 단순 합산이 아님. 환변동 계량치는 미확보 — 후속 소싱 항목
2. **산술 vs 기하**: 프리셋은 기하평균 기준 (Damodaran 산술 11.79%와 혼동 금지)
3. **과거≠미래**: DMS 포워드 ERP는 연 3~3.5%로 실현치(4.3~4.6%)보다 낮음 → 주식 실질수익 50~150bp 하향 여지. Damodaran ERP 표준오차 ±2.12% → "기본(보수)/역사적(공격)" 이중 프리셋 또는 불확실성 표시 권장
4. **금 레짐 민감**: 측정 시작점에 따라 실질 0.6%~4.9%까지 벌어짐 — 단일값 과신 금지, 앱 내 "기간 민감" 주석
5. **생존·선택 편향**: DMS 국가평균(특히 채권 0.6~0.9%)은 초인플레 국가 포함 여부로 크게 흔들림 — 한국 국고채를 미국치로 대체하면 상방 편향
