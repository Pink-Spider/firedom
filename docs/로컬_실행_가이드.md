# 로컬 실행 가이드 — Android 에뮬레이터 / iOS 시뮬레이터

이 프로젝트는 fvm으로 Flutter 버전을 고정한다(3.44.5). 모든 명령은
**프로젝트 루트**에서 `fvm flutter ...`로 실행한다.

## 0. 사전 준비 (1회)

- **fvm**: `fvm install` (`.fvmrc`의 버전을 받아온다)
- **iOS**: Xcode + CocoaPods (`brew install cocoapods`)
- **Android**: Android Studio + AVD 1개
  (현재 머신에는 `Medium_Phone_API_36.1`이 만들어져 있음)
- 상태 점검: `fvm flutter doctor`

## 1. 에뮬레이터 부팅

```bash
# iOS 시뮬레이터
xcrun simctl boot "iPhone 16 Pro"
open -a Simulator

# Android 에뮬레이터
fvm flutter emulators --launch Medium_Phone_API_36.1
```

부팅된 기기와 ID 확인:

```bash
fvm flutter devices
# 예)
#  sdk gphone64 arm64 (mobile) • emulator-5554  • android-arm64
#  iPhone 16 Pro (mobile)      • 95EF1B76-...   • ios
```

## 2. 앱 실행 ★

> **에뮬레이터를 부팅해도 앱이 저절로 설치되지는 않는다.**
> 홈 화면에 아이콘이 없는 게 정상 — `flutter run`이
> **빌드 → 설치 → 실행**을 한 번에 해준다.

```bash
# Android (기기 ID는 flutter devices에서 확인, 보통 emulator-5554)
fvm flutter run -d emulator-5554

# iOS (기기 이름으로 지정 가능)
fvm flutter run -d "iPhone 16 Pro"
```

- **첫 빌드는 수 분 걸린다** (iOS는 pod install, Android는 Gradle
  다운로드 포함). 완료되면 앱이 자동으로 열린다
- 실행한 터미널은 앱과 연결된 채 유지된다 — 여기서 핫 리로드를 쓴다
- `q`로 종료해도 앱은 설치된 상태로 남아 홈 화면 아이콘으로 다시 열 수
  있다 (디버그 빌드라 단독 실행은 다소 느릴 수 있음)
- 두 기기 동시 실행: 터미널 2개에서 각각 실행(로그 보기 편함),
  또는 한 터미널에서 `fvm flutter run -d all`

### 실행 중 단축키

| 키 | 동작 |
|---|---|
| `r` | 핫 리로드 (코드 수정 반영) |
| `R` | 핫 리스타트 (상태 초기화) |
| `q` | 종료 |

## 3. 플랫폼별 테스트 팁

### iOS

- 생체인증: Simulator 메뉴 **Features → Face ID → Enrolled** 체크 후,
  인증 요청이 뜨면 **Features → Face ID → Matching Face**
- 알림: 설정 화면에서 리마인더를 켜면 권한 팝업이 뜬다
- **홈 위젯은 Xcode에서 Widget Extension 타겟을 추가한 뒤에만 동작**
  → `docs/W1_홈위젯_iOS_설정.md` 참조

### Android

- 홈 위젯: 홈 화면 길게 누르기 → 위젯 → 파이어덤 추가
- 알림 권한(API 33+): 리마인더를 켤 때 팝업이 뜬다

## 4. 확인 체크리스트 (핵심 루프 한 바퀴)

1. **온보딩(S1→S2)**: 4문항 입력(예: 35세/500만/300만/1억) →
   "FIRE 나이 54세" + What-if 슬라이더 → "이 계획 시작하기"
2. **홈(S3)**: D-day·진행률 확인, 기록 유도 카드
3. **기록(S5→S8)**: 하단 탭 (+) → 항목 금액 입력 → 저장 →
   결과 리빌(카운트업·저축률) → 2번째 달부터 궤도 편차 배지
4. **시뮬레이션(S4)**: 슬라이더 조작 → 즉시 재계산,
   "성공 확률 계산하기" → isolate 실행 (UI 안 멈추는지 확인)
5. **목표 설정(S7)**: 홈 상단 튠 아이콘 → 국민연금 입력 →
   브릿지 분리 계산 → 저장 → 홈 궤도 반영 + 리비전 마커
6. **자산(S6)**: 자산배분 도넛, 목표 배분 편차, 현금흐름
7. **설정(S10)**: 리마인더 켜기(권한 팝업), 금액 가림, 생체인증 잠금,
   백업 내보내기/가져오기(공유 시트)
8. **유료 게이트**: 설정 → "프리미엄 시뮬레이션 (디버그)" 켜기 →
   시뮬 탭에서 "상세 분포 보기" → p10/p50/p90 + 고갈 나이 분포

## 5. 트러블슈팅

- **iOS pod 오류**: `cd ios && pod install --repo-update` 후 다시 run
- **Android 첫 빌드가 느림**: Gradle 의존성 다운로드 때문 — 정상.
  desugaring 설정(`isCoreLibraryDesugaringEnabled`)은 이미 적용돼 있다
- **기기가 안 보임**: `fvm flutter devices`로 확인, 에뮬레이터 부팅
  완료(홈 화면 표시)까지 기다린 후 재시도
- **데이터 초기화**: 시뮬레이터/에뮬레이터에서 앱 삭제 후 재설치
  (DB·설정 모두 기기 내에만 있음)
- **빌드 캐시 꼬임**: `fvm flutter clean && fvm flutter pub get`
