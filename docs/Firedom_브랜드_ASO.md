# Firedom — 브랜드 & 스토어 등록(ASO) 가이드

작성일: 2026-07-08 | 상태: 초안 (상표·핸들 확인 전)

---

## 1. 브랜드 기본

- **영문**: Firedom (FIRE + Freedom)
- **한글 표기: 파이어덤** (권장)
  - '파이리덤'이 freedom의 어감은 살리지만, 유저는 스토어에서 "파이어"로 검색한다. '파이어덤'은 핵심 검색어 '파이어'와 **접두 일치**해서 ASO에서 유리
- 브랜드 한 줄: **"불을 지피는 자유 — 매달 기록하며 재정적 자유의 D-day를 앞당기는 앱"**
- 마케팅 캠페인 카피(앱명과 분리 운용): "당신의 퇴사시계는 몇 시인가요?"

## 2. 확정 전 체크리스트 (순서대로, 하나라도 걸리면 재논의)

- [ ] App Store(한국·미국) / Play스토어에서 "Firedom", "파이어덤", "파이리덤" 검색 — 동명·유사 앱 확인
- [ ] KIPRIS 상표 검색 — 9류(소프트웨어), 36류(재무·금융 정보 제공), 42류(SaaS)
- [ ] 도메인: firedom.app / firedom.kr / getfiredom.com 중 1개 이상
- [ ] SNS 핸들: @firedom_app 등 인스타·X·유튜브
- [ ] iOS 번들ID·Android 패키지명 예약: `app.firedom.*` (조직 도메인 확정 후)
- [ ] 참고: 영어권에서 "firedom"이 총기(firearm) 커뮤니티 은어로 쓰이는 용례가 있는지 확인 (글로벌 확장 시)

## 3. App Store 메타데이터 초안

- **제목** (30자): `파이어덤 Firedom` (16자 — 여유분은 비워두기, 키워드 스터핑은 리젝 사유)
- **서브타이틀** (30자): `파이어족 은퇴 계산기·자산 기록` (15자)
  - 대안: `조기은퇴 시뮬레이션과 월간 자산 기록`
- **키워드 필드** (100자, 쉼표 구분·공백 없이):
  `파이어,파이어족,조기은퇴,은퇴계산기,경제적자유,순자산,저축률,자산기록,재무설계,연금,국민연금,몬테카를로,FIRE,fire,4%룰`
  - 제목·서브타이틀에 이미 있는 단어는 중복 배치하지 않는다 (지면 낭비)
- **프로모션 텍스트** (170자, 심사 없이 수시 변경 가능): 시즌 카피 운용. 예: "새해 목표가 조기은퇴라면 — 60초 만에 나의 FIRE 나이를 확인하세요."
- **심사 노트(Review Notes) 필수 기재**: 계좌 연동 없음 / 자금 이동·거래 기능 없음 / 모든 데이터 유저 수기 입력·기기 로컬 저장 / 시뮬레이션은 정보 제공 목적(투자자문 아님) / 구독 테스트 계정 불필요(무계정 앱)

## 4. Play스토어 메타데이터 초안

- **제목** (30자): `파이어덤 Firedom: 파이어족 은퇴 계산기`
- **짧은 설명** (80자): `나의 FIRE 나이를 60초 만에. 매달 자산을 기록하면 조기은퇴 계획 대비 궤도를 보여드립니다.`
- **긴 설명 도입부** (첫 문단이 검색·전환 핵심):
  > 몇 살에 은퇴할 수 있을까? 파이어덤은 나이·소득·지출·자산 4가지만 입력하면 당신의 FIRE 나이를 계산하고, 매달 자산을 기록할 때마다 계획보다 앞서는지 뒤처지는지 보여주는 파이어족 전용 궤도 추적 앱입니다.
  >
  > ✓ 회원가입 없음 ✓ 계좌 연동 없음 ✓ 모든 데이터는 내 기기에만 저장
- **긴 설명 본문 구성**: 핵심 루프 설명 → 기능 목록(무료/프리미엄 구분 명시) → 한국형 특화(국민연금 브릿지, 연금계좌) → 프라이버시 선언 → 면책 문구("본 앱의 시뮬레이션은 정보 제공 목적이며 투자 자문이 아닙니다")
- **금융 기능 선언**: "금융 기능 제공 안 함" 제출 (전체 앱 의무 사항)

## 5. 스크린샷 스토리보드 (양대 스토어 공통, 5~6장)

1. **훅**: 온보딩 결과 화면 — "당신의 FIRE 나이 52세" (앱의 광고판을 그대로)
2. What-if 슬라이더 — "+30만원이면 3년 단축"
3. 홈 궤도 차트 — "계획보다 3개월 앞서는 중"
4. 월 스냅샷 기록 — "한 달에 3분, 기록 리추얼"
5. 위젯 — "홈 화면에서 매일 D-day 확인"
6. 프라이버시 — "서버 없음. 데이터는 당신 기기에만"

주의: 스크린샷·설명 어디에도 '투자', '자산관리 서비스', 수익률 보장형 문구를 쓰지 않는다 (3.2.1(viii) 오인 방지 + 표시광고 리스크).

## 6. 네이밍 결정 기록 (ADR)

- 후보군: 파이어로그(스토어 선점으로 탈락), 모닥, 돈독("돈독 오르다" 부정 속어 리스크로 보류), 파이어플라이(Adobe Firefly 충돌 탈락), 자유시간(크라운제과 상표 탈락), 퇴사시계(제품 축소 인지·신뢰 톤 불일치로 앱명 탈락, 마케팅 카피로 전용)
- **Firedom 선정 이유**: FIRE+Freedom 조어로 고유성과 의미 전달의 균형, 발음 용이, 글로벌 확장 시에도 사용 가능. 한글 '파이어덤' 표기로 '파이어' 검색 접두 일치 확보
